# 🚀 Seniru Kasthuriarachchi Portfolio

A modern, responsive full-stack developer portfolio built using **Next.js 15**, **TailwindCSS**, **React 19**, and **Radix UI** components. Showcases skills, experience, and projects in a clean and interactive design.

## 📂 Features

- ⚡️ Built with Next.js 15 and React 19
- 🎨 Styled using TailwindCSS and TailwindCSS Animate
- 🌗 Light/Dark theme support via `next-themes`
- 🧩 Modular and reusable components with Radix UI
- 🧠 Form handling using `react-hook-form` and `zod`
- 📊 Visualizations with `recharts`
- 🎠 Embla Carousel for interactive sliders
- 🔐 OTP inputs with `input-otp`
- 💬 Toast notifications using `sonner`
- 🔧 TypeScript support
- 📱 Fully responsive design
